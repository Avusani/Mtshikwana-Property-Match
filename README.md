# Mtshikwana Property Match

## 🏠 Intelligent Tenant & Landlord Matching System

Mtshikwana Property Match connects tenants with landlords using smart matching algorithms. Built with Node.js, Express, and MongoDB for persistent data storage.

### ✨ Features

- **Smart Matching Algorithm** - Matches tenants with properties based on location, budget, room type, and preferences
- **Admin Dashboard** - Manage landlords, tenants, matches, and appointments
- **Calendar View** - Visualize and manage appointments
- **WhatsApp Integration** - Direct communication between tenants and landlords
- **Responsive Design** - Works on all devices
